# Project Story

## Origin

The prototype is inspired by marketplace vendor onboarding and assortment
problems encountered while managing a multi-vendor e-commerce platform.

## Product problem

Vendor evaluation becomes difficult as the marketplace scales because
important business characteristics are not directly observable in a single
field.

## Analytical hypothesis

Observable operational, commercial, catalogue and customer signals contain
lower-dimensional latent structure that can support vendor decisions.

## Prototype boundary

This repository is a retrospective analytics prototype using synthetic data.
It is not a claim of production deployment or historical production impact.
